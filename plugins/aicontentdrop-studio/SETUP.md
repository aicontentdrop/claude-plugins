# Setup

## From the marketplace

In Claude Code:

```text
/plugin marketplace add aicontentdrop/claude-plugins
/plugin install aicontentdrop-studio@aicontentdrop
```

On claude.ai and in Claude Desktop: **Customize > Plugins > Add > Add marketplace**, enter `aicontentdrop/claude-plugins`, install **AI Content Drop Studio**, then add and sign in to **AI Content Drop** on the plugin's **Connectors** tab. The [README](./README.md) covers every surface, the connector on its own, and the CLI.

## From a local clone

Load the plugin for one session without installing anything:

```bash
git clone https://github.com/aicontentdrop/claude-plugins
claude --plugin-dir claude-plugins/plugins/aicontentdrop-studio
```

Check the manifest and the marketplace before loading them:

```bash
claude plugin validate --strict claude-plugins/plugins/aicontentdrop-studio
claude plugin validate --strict claude-plugins
```

## Sign-in

The connector is `https://aicontentdrop.com/mcp`. `list_models`, `estimate_credit_cost`, `list_ad_formats`, `list_ugc_avatars` and `estimate_ad_cost` answer without an account. Every other tool needs an account: most are listed before sign-in and ask for it on first use, and the drop and drama tools are listed only once you have signed in. In Claude Code, sign in with `/mcp` and select **aicontentdrop**; on claude.ai and in Claude Desktop, on the plugin's **Connectors** tab. Sign-in is OAuth on aicontentdrop.com. No API key is needed, and the commands never ask for one.

## Money

Every command quotes a paid step, tells you the number, and goes ahead only after you say yes; the drama writing step is told to you as paid before the call and its number right after. Credits are charged only when the step succeeds. Plan questions go to <https://aicontentdrop.com/plans>.

## Try it

```text
/aicontentdrop-studio:models video models up to 20 credits, and quote one 5-second clip on the cheapest
/aicontentdrop-studio:make a 5-second vertical clip of a matcha latte being poured, product-ad style
/aicontentdrop-studio:ad Nimbus Tea, a cold-brew tea in a can; smooth, no sugar, 20 calories; shop the launch
/aicontentdrop-studio:research cold brew tea on meta
/aicontentdrop-studio:board Launch week, three hooks for Nimbus Tea and one product still to animate
/aicontentdrop-studio:drop a launch week of short vertical videos for Nimbus Tea
/aicontentdrop-studio:recreate https://example.com/reference.mp4, a 15-second vertical ad in this style for Nimbus Tea
/aicontentdrop-studio:drama a disowned heiress returns as the new owner of her family's hotel, 3 episodes of 30 seconds
```

## Updating

The plugin follows the repository. Skills under `skills/` and the marketplace copy under `plugins/aicontentdrop-studio/` are generated by `npm run build:claude-plugin-studio` from the shared source; edit the source, rerun the script, and commit everything it wrote.
